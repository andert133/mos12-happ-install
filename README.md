# Happ для MOS 12 / РОСА Linux

Скрипт автоматической установки **Happ** на MOS 12 / РОСА Linux.

Скрипт проверяет зависимости, устанавливает RPM-пакет и при необходимости загружает недостающие библиотеки отдельно, не изменяя системные файлы. Логи и отчёты сохраняются для диагностики.

## Что понадобится

* MOS Desktop / РОСА Linux
* Интернет
* `sudo`
* Файл установки Happ `.rpm`

## Установка

### 1. Скачайте скрипт

Скачайте файл [`smart-dnf-install`](./smart-dnf-install) из этого репозитория.

### 2. Скачайте RPM-файл Happ

Скачайте актуальный RPM-файл Happ по ссылке:

**[Скачать Happ.linux.x64.rpm]([https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.linux.x64.rpm])**

После скачивания положите `Happ.linux.x64.rpm` **в ту же папку**, где находится `smart-dnf-install`.

В итоге в папке должны находиться:

```text
smart-dnf-install
Happ.linux.x64.rpm
```

### 3. Откройте терминал в этой папке

Откройте терминал непосредственно в папке с файлами.

### 4. Запустите установку

Сначала сделайте скрипт исполняемым:

```bash
chmod +x smart-dnf-install
```

Затем запустите установку:

```bash
sudo ./smart-dnf-install --auto Happ.linux.x64.rpm
```

Введите пароль пользователя, если система его запросит.

> При вводе пароля в терминале символы могут не отображаться — это нормально.

### 5. Дождитесь завершения

Скрипт автоматически выполнит необходимые действия.

При успешной установке появится:

```text
УСТАНОВКА ЗАВЕРШЕНА ✅
```

После этого откройте меню приложений, найдите **Happ** и запустите его.

## Если что-то пошло не так

### `sudo: command not found`

Убедитесь, что используется MOS / РОСА Linux и что команда введена полностью.

### `Пароль неверный`

Проверьте пароль и раскладку клавиатуры.

### `dnf: команда не найдена`

Скрипт рассчитан на системы MOS / РОСА с пакетным менеджером `dnf`.

### `УСТАНОВКА С ЗАМЕЧАНИЯМИ`

Установка могла завершиться частично. Проверьте работу Happ.

Для диагностики рядом со скриптом может быть создана папка:

```text
smart-dnf-work/
├── RESULT.txt
└── logs/
```

`RESULT.txt` содержит результат установки, а `logs/` — подробные журналы.

### Happ запускается, но не подключается

Это уже не связано непосредственно с установкой. Проверьте ключи или подписку в настройках Happ.

## Удаление

Для удаления Happ выполните:

```bash
sudo rpm -e happ
```

При необходимости удалите файлы приложения:

```bash
sudo rm -rf /opt/happ
```

---

## Как это работает

Скрипт устанавливает Happ из переданного RPM-файла.

Если системе не хватает необходимых библиотек, скрипт пытается загрузить их отдельно в `/opt/happ`, не изменяя системные библиотеки.

Логи и результаты работы сохраняются в `smart-dnf-work` рядом со скриптом.
